# GDS 5대 확신 암송 퀴즈

순복음대구교회 **GDS실 스탭**을 위한 5대 확신 성경 암송 점검 앱입니다. (개역개정)

## 진행 방식

확신마다 두 단계로 진행합니다.

1. **성경 구절 입력** — 예) `요한일서 5장 11~12절`, `요일 5:11-12` 모두 인정
2. **말씀 본문 입력** — 어절 단위로 채점하고 틀린 곳을 표시

채점 표시

| 표시 | 뜻 |
| --- | --- |
| 빨강 취소선 | 잘못 쓴 단어 |
| 노랑 밑줄 | 빠뜨린 단어 |
| 파랑 점선 | 띄어쓰기만 다른 곳 (정답 처리) |

문장부호와 대소문자는 채점에서 무시합니다. 띄어쓰기 차이는 정답으로 인정하되 몇 곳인지 알려 줍니다.

## 말씀 타자 연습 (`typing.html`)

암송이 부담스러운 분들을 위한 타자 연습 게임입니다. 같은 5대 확신 본문을 씁니다.

- **따라 치기** — 말씀을 보면서 그대로 입력합니다. 글자 단위로 맞고 틀림을 색으로 보여 주고, 타수(두벌식 자판 누름 수 기준)와 정확도를 실시간으로 계산합니다.
- **낱말 비 피하기** — 말씀의 낱말이 위에서 떨어집니다. 바닥에 닿기 전에 쳐서 없애면 점수와 콤보가 오릅니다. 6개마다 단계가 오르며, 낙하 시간과 생성 간격은 각각 2.4초·0.6초에 수렴하도록 완만하게 줄어듭니다. 화면에 동시에 뜨는 낱말은 4~7개로 제한해 후반에도 폭주하지 않습니다. 점수에는 단계 배수가 곱해집니다. 목숨 3개.

최고 기록은 `localStorage`에 남습니다. 탭을 다른 곳으로 옮기면 낙하가 멈췄다가 돌아올 때 이어집니다.

## 5대 확신

| # | 확신 | 구절 |
| --- | --- | --- |
| 1 | 구원의 확신 | 요한일서 5:11~12 |
| 2 | 기도 응답의 확신 | 요한복음 16:24 |
| 3 | 승리의 확신 | 고린도전서 10:13 |
| 4 | 사죄의 확신 | 요한일서 1:9 |
| 5 | 인도의 확신 | 잠언 3:5~6 |

## 실행

빌드 도구가 필요 없는 정적 페이지입니다.

```bash
npx serve .
```

Vercel에 그대로 배포하면 됩니다. (Framework Preset: Other / 빌드 명령 없음)

## 구성

- `index.html` / `app.js` — 암송 퀴즈 (구절 파싱, 채점 LCS diff, 화면 전환)
- `typing.html` / `typing.js` / `typing.css` — 타자 연습 두 가지 모드
- `styles.css` — 공통 스타일
- `data.js` — 말씀 본문과 책 이름 별칭 (두 페이지가 함께 씀)

점수 기록은 브라우저 `localStorage`에 최근 20회까지 저장되며 서버로 전송되지 않습니다.
